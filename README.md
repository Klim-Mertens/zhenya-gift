# Лето Жени

Пиксельная браузерная игра-подарок на день рождения. Ноутбук, любой современный браузер.

## Как запустить

Открой `index.html` в браузере или зайди на страницу GitHub Pages этого репозитория.
Сборка не нужна: только HTML, CSS и JavaScript.

Управление: стрелки или WASD — ходить, пробел или E — говорить и действовать, M — звук.
В квесте с чемоданом: тянуть вещи мышкой, правый клик или R — повернуть.

## Что внутри

- `src/art/` — вся графика рисуется кодом по пикселям (люди, комнаты, вокзал, поезд, вещи).
- `src/scenes/` — сцены Phaser: титул, квартира родителей, сборы чемодана, вокзал, поезд.
- `src/audio.js` — музыка и звуки синтезируются в браузере, без аудиофайлов.
- `src/ui.js` — диалоги, цели и подсказки поверх игры (HTML, чёткий шрифт Tiny5).
- `vendor/phaser.min.js` — движок Phaser 3.90 (лицензия MIT, см. `vendor/PHASER-LICENSE.md`).

Для проверки отдельной сцены: `index.html?scene=home`, `pack`, `station` или `ride`.
